One assistant. Every request takes the cheapest path that works.

APEX-AI is a fully containerized personal assistant. A local small model screens each request, Groq handles fast reasoning, hybrid RAG supplies context, and a custom PyTorch CNN reads images on-device.

AI features

  
What the assistant can do, and the engineering behind each feature.

  

    
Streaming answers
Tokens and tool-call badges arrive over Server-Sent Events as they are produced.

    
Voice in and out
Speak a request with Groq Whisper Turbo and hear the reply through Edge-TTS or Kokoro.

    
Tool use through MCP
Connect GitHub, SQLite and file-system servers without custom glue code.

    
Answers with sources
Hybrid RAG cites the passages and graph facts it used, so claims can be checked.

    
Image understanding
Documents and objects are classified on-device first. Only unclear images go to the cloud.

    
Personal memory
Remembers the session, past conversations and the facts and preferences you share.

    
Cost-aware routing
A local model handles triage for free. Groq is used only when reasoning is needed, and the 8B model takes over under rate limits.

    
Safe by default
Injection checks run locally before any cloud call. Outputs follow strict JSON schemas.

    
Observable
Every run logs latency, tokens and cost as structured JSON, with OpenTelemetry traces.

  





  
How the agent thinks

  

    
Plans, acts, corrects
A LangGraph state graph runs dynamic planning and multi-step loops. A failed tool call sends its stack trace back to the model, which repairs the parameters and retries.

    
Never stalls on rate limits
Fallback nodes switch from llama-3.3-70b-versatile to llama-3.1-8b-instant, or to the local model, when Groq limits are reached.

    
Connects to real tools
A native MCP client attaches to standard tool servers such as SQLite, GitHub and the local file system.

    
Strict outputs
Pydantic and Instructor enforce JSON schemas on every tool call and API response.

  






  
Hybrid retrieval: vectors plus a knowledge graph

  

    
Find
  • Semantic chunking on ingest
  • Dense search with bge-small-en-v1.5
  • Sparse BM25 keyword search

    
Connect
  • Entities and relations stored in Neo4j
  • Graph context injected next to retrieved passages
  • Answers reason over relationships, not just similar text

    
Trim
  • FlashRank reranking
  • Contextual compression
  • Dynamic trimming to fit the Groq context window

  






  
Vision with two tracks

  

    
Fast track
The local CNN, a ResNet or EfficientNet derivative on ONNX Runtime, classifies layouts, objects and safety markers in under 20 ms.

    
Deep track
When the CNN is unsure, the image escalates to a Groq vision-capable endpoint for open-ended analysis.

  






  
Three kinds of memory

  

    
WorkingRedis ring buffer holding the active session.

    
EpisodicPast interactions and context, stored as vectors.

    
SemanticExplicit facts, preferences and entities in SQLite or Neo4j.

  

  
Voice runs on Groq Whisper Turbo for speech-to-text and Edge-TTS or Kokoro ONNX for speech output.






  
Guardrails and observability

  

    
Local-first injection defense
Regex rules and Llama-Guard run in the SLM layer, so hostile prompts are blocked before any cloud call.

    
Measured runs
OpenTelemetry and structured JSON logs record latency, tokens (TPM and RPM) and cost for every agent run.

Run it

  
The repository layout and the core of the compose file. Replace the placeholders with your own keys.


git clone https://github.com/Nikhil-creat/apex-ai.git
cd apex-ai
cp .env.example .env      # add GROQ_API_KEY
docker compose up --build

# docker-compose.yml (excerpt)
services:
  apex-gateway:  { image: nginx:alpine, ports: ["443:443"], depends_on: [apex-agent, apex-ui] }
  apex-agent:    { build: ./agent,  env_file: .env, depends_on: [apex-vectordb, apex-graphdb, apex-vision] }
  apex-vision:   { build: ./vision }
  apex-vectordb: { image: qdrant/qdrant, volumes: ["qdrant:/qdrant/storage"] }
  apex-graphdb:  { image: neo4j:5, volumes: ["neo4j:/data"] }
  apex-ui:       { build: ./ui }
